# Packages

* `autoskill-local/` (Phase 3): the user-side CLI (`autoskill login|trial|install`) and the
  `autoskill-companion` MCP server that installed skills call for checkpoints and telemetry.
* `skill-templates/` (Phase 2): SKILL.md and references skeletons used by the drafting agent.
* `mcp-server-template/` (Phase 6): Jinja2 tree used to generate FastMCP servers from deterministic steps.
